## 5. Планируемые тестовые идеи

Ниже — будущие oracles из reports/плана, не выполненные проверки.

- **Unit:** dirty whitelist/SQL-safe strings, HEX/URL и contrast helpers; trim/raw имя/роль/текст с padded raw82/trim80; old/malformed widget DTO; unsafe runner configuration; mutation белого heading и отсутствующей связи ошибки.
- **Интеграция:** отдельная PostgreSQL с существующими миграциями, grants/RLS и контекстом настоящих statements; одновременные patches и rollback; newest-50 ordering, provenance/badge; настоящий локальный SDK PUT/GET и управляемый 503 без внешнего обращения.
- **E2E/visual/AT:** обычный login и navigation, Save/reload/public effect, delayed response и две вкладки, legacy HTTP logo, photo→pending→approve и retry; production view components с frozen literal model, два экрана × три размера и zero diff плюс font/margin/color mutations; отдельные живые маршруты для keyboard/focus, computed contrast и reflow 320/360/390, отдельный ручной screen-reader на согласованной test copy. Static fixture не доказывает интерактивность.
