Это устранит противоречие, не расширяя проверку до серверного сохранения.

## Ограничения независимой проверки

- `blocked-requests.json` содержит пустой массив. Это не полный журнал разрешённых запросов и не самостоятельное доказательство эффективности guard. Разрешение только login и текстового `POST /api/import` с `mode=preview`, отсутствие commit/checkout/других записей приняты как описание действий автора 08, а не независимо восстановленная сетевая трасса. DOM preview и статический обработчик согласуются с этим описанием.
- Не наблюдены: OCR/файловые uploads, получение отзывов по внешней ссылке, commit импорта, отправка текстового/видеоотзыва, запись с рабочей камеры, модерация/редактирование/удаление/перестановка реальных отзывов, заполненный embed, платежи, платные стены и кампании. Статические handlers не закрывают эти пробелы.
- Содержимое DOM не доказывает адаптивную геометрию, доступность, серверную валидацию или отсутствие всех побочных эффектов GET/login. Скриншоты и мобильная геометрия в этом focused review не проверялись. Reuse Proofwall и предложенные AC не перепроверялись по исходникам и не считаются результатами тестов.
- Использованы только локальное чтение и разбор JSON/Markdown. Браузер, сеть, тесты, runtime API, секреты и профиль не открывались. Recall CLI не запускался в рамках заданного ограничения на локальную выборочную проверку без дополнительных действий. Изменён только этот отчёт; исходные артефакты не копировались.
