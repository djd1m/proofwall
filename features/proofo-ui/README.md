# Воспроизведение UI/UX Proofo в Proofwall

Запрос владельца 11.11.2026: изучить https://proofo.ru/ и воспроизвести все пользовательские UI/UX сценарии в существующем Proofwall с cross-model проверкой.

Стадия: аудит референса и текущего проекта. Реализация интерфейса не начата.
Актуальный полный план: [06_team_execution_plan.md](06_team_execution_plan.md).
Проверка full-QE и хуков: [11_process_verification.md](11_process_verification.md).
Публичный и разрешённый авторизованный аудит выполнены. Содержание недоступных платных и заполненных состояний не восстанавливается по предположениям.

Планируемая последовательность: evidence → карта сценариев/различий → feature-adr/OpenSpec → desktop/mobile макеты → согласование владельца → реализация → независимые visual/E2E/QE → ручная приёмка на VPS.

Команда: координатор и frontend — gpt-6.1-sol high; исследование — отдельные gpt-6.1-sol high; UX/архитектура/план — gpt-6-astra xhigh; code QE — новая gpt-6-astra xhigh; документы Astra проверяет другая модель (gpt-6.1-terra xhigh). Только фактические запуски называются выполненными.

Среда сохраняется: /home/proofwall, Next.js, PostgreSQL, Cloud.ru S3, Docker/Caddy. Production/DNS не переключаются. После замены credentials Cloud.ru S3 проверен успешно; прежний отказ 403 относится к историческому этапу.

Подтверждены 15 HTML-страниц, сохранены скриншоты, браузерные измерения и хеши.

Пять экранов/шаблонов: главная, вход, восстановление пароля, стена и установка виджета.
Все явно обозначены как демонстрационные.

Две отдельные исследовательские сессии Sol, архитектор Astra и независимый проверяющий
Terra фактически запущены. Финальный QE рабочего приложения не проводился: его интерфейс
ещё не заменялся. Замечания по пояснениям макета, favicon и описанию изменений Caddy
исправлены и проверены независимым исполнителем.

Опубликован отдельный статический макет через Caddy; файлы apps/, packages/ и services/
в этой фазе не изменялись.

Проверены обзор стен/метрики, три режима импорта, текстовый предпросмотр без commit,
оформление и несохранённые изменения, смена пароля с отменой, текстовая/видеоформы,
отмена file chooser, отсутствие камеры в тестовом контексте и все четыре якоря секций.
Платные сценарии, заполненные review-карточки и успешный OCR/upload не проверялись.
Исходные credentials, Chromium profile, sanitized DOM и закрытые скриншоты остаются
локально в ignored .secrets; в Git и публичный макет они не переносились.
App-код, настройки проектов Proofo и опубликованный UI Proofwall не изменялись.
