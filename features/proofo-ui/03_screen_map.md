## Измеренный визуальный ориентир

`measurements.json` фиксирует 1440 px и 390 px для главной, входа и domotour; help измерен только на 1440 px. Это не полная responsive-матрица. На desktop основной контейнер главной 1180 px; H1 68 px, на mobile 38 px. Стена: три карточки примерно по 379 px при 1440; одна 358 px с полями 16 px при 390. Цвет страницы стены `rgb(242,237,227)`, карточки `rgb(255,253,248)`, radius 14 px. Эти факты — отправная точка макета, не универсальные значения для всех компонентов.

Для честного сравнения нужны фиксированные данные/шрифты, одинаковый viewport и full-page capture. Длинный контент и реальная высота страницы входят в приёмку. Ни legal, ни forgot, ни все platform-варианты не получили отдельного visual-baseline этим проходом; до заявления визуальной полноты их нужно доснять.
