# Следующий инкремент: кабинет стены

Статус: **макет и план до реализации**. Действующий UI preview остаётся на проверенной
сборке `xl_3mKgt4IwcnieD7U4fy`; продуктовый код этого инкремента не изменён.

[Посмотреть предлагаемую адаптацию](https://proofwall.78.17.53.233.sslip.io/__design/proofo/project-next/).
В ней можно переключить пустую стену/две предложенные карточки, ручной перенос/CSV,
действия модерации и секции кабинета. Это локальная демонстрация с вымышленными данными.

## Что сохраняется

Бумажная оболочка, терракотовая палитра и контрастные границы; первые шаги,
действующие ручной перенос со скриншотом/ссылкой и CSV preview/commit, модерация,
код виджета и ссылки сразу после создания стены, текущие тариф/N3, share-CTA,
смена пароля и email recovery. Публичный пользовательский accent сохраняется
независимо от палитры самого кабинета.

OCR, автоматический поиск по ссылке, несуществующие Start/Pro условия и кампании
не объявляются работающими функциями. Отличия подробно описаны в
[адаптации](design-adaptation.md) и [описании макета](preview/README.md).

## Предкодовые условия

Ожидается решение владельца по конкретной адаптации/filled states. Обязательная
граница — AGENTS: «Перед реализацией UI показать конкретный макет владельцу и
согласовать его». Нельзя считать прошедшее время ответом или приёмкой.

Design rework завершён; originating reviewers независимо подтвердили свои
условия на новой ревизии. Native review history и отказы сохранены. K1/K2,
source admission, реализация, product tests и новый deploy ещё не выполнены.
Состояние planned, receipt отсутствует; ручной synthetic handler probe подтвердил
отказ записи product source, не выдаётся за реальное событие native author.

После согласования: завершить gates → Sol author с native hooks → применимые
тесты/visual/runtime → независимый cross-model QE → отдельная тестовая копия.
GitHub CI отложен; DNS и production относятся к отдельному решению.
