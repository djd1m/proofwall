# Макет кабинета стены: структура Proofo

Редакция 16.11.2026 по поручению владельца: вернуть структуру и три способа переноса Proofo, скрыть CSV и технические настройки. Это отдельный статический макет для согласования, без продуктовой реализации и сохранения данных.

Опубликован: https://proofwall.78.17.53.233.sslip.io/__design/proofo/project-next/

## Основной сценарий

Порядок: заголовок стены → первые шаги → перенос → отзывы → «Показать людям» → сбор новых отзывов → кампании → тарифы → пароль. Сохранены бумажная оболочка, локальные шрифты, терракотовый акцент `#c8492f` и контрастные границы `#8e806b`. Родительские исходные ресурсы `/__design/proofo/` не изменены.

Три основные вкладки в порядке Proofo:

1. **Со скриншотов** — начальная вкладка, выбор или перенос до 20 PNG/JPEG, затем «Распознать». Проверяются только количество, имя и MIME файлов; содержимое не читается и не отправляется. Нажатие сообщает, что распознавание ещё не подключено, без выдуманного результата.
2. **Вставить текстом** — по строке `Имя; текст отзыва`, локальный предпросмотр всех корректных строк и отдельная демонстрационная кнопка добавления. Ошибочный формат не даёт продолжить; изменение текста сбрасывает предпросмотр. Стена не изменяется.
3. **По ссылке** — поле HTTP/HTTPS, ограничения источников и «Посмотреть, что найдётся». Поиск не подключён: нет внешнего запроса и результата извлечения.

Вкладки переключаются мышью и клавиатурой (стрелки, Home/End, Enter/Space). Черновики сохраняются при переключении, исчезают после перезагрузки.

При пустой стене адрес и код виджета скрыты. Оформление и форма сбора доступны сразу. Кампании и карточки Start/Pro восстановлены визуально по исследованному Free-состоянию Proofo; это не новые условия или работающие тарифы Proofwall. Оплата отключена.

## «Дополнительно»

Раздел закрыт по умолчанию. Внутри сохранены CSV с локальным предпросмотром и сопоставлением колонок, подробный ручной перенос, технические N3/share-состояния, текущий платёжный сценарий Proofwall и восстановление email. Они отсутствуют в основном сценарии переноса.

Здесь же переключатель «Пустая стена / 2 демоотзыва»: он показывает предложенные карточки модерации и демонстрационные адрес/код. Заполненное состояние Proofo не наблюдалось. Карточки и переходы статусов — только локальный образец с вымышленными данными.

## Границы и проверка

Нет API, авторизации, БД, браузерного хранилища, OCR, загрузки медиа, поиска по ссылкам, писем и платежей. Только явно выбранный CSV читается как локальный текст (до 64 КБ); изображения не читаются. Вывод введённого текста через `textContent`; CSP запрещает подключения, отправку форм и inline JS/CSS. Копирование демокода в буфер выполняется только по нажатию. Код виджета содержит `example.invalid` и не исполняется. Поля пароля отключены.

Проверка этой редакции: `../evidence/structure-restoration-2026-11-16.json`. Это авторская браузерная проверка статического макета, не независимое QE, приёмка владельца или готовность приложения.

Старый план адаптации с двумя вкладками и прежние QCSD-результаты сохранены как история. До продуктовой реализации нужно согласовать обновлённую нормативную дельту и план; эта правка макета не выдаёт source admission и не меняет production.
