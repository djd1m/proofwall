# Proofwall — публичный UI preview

Статический прототип для согласования UI, не реализация продукта. Открыть `index.html` в Chrome либо запустить из этого каталога `python3 -m http.server 8091` и перейти на http://localhost:8091/.

Экраны: `?screen=home` (hero, how, pricing, signup), `?screen=login`, `?screen=forgot`, `?screen=wall`, `?screen=install`. Добавить `&clean=1`, чтобы скрыть панель выбора экранов для снимка. Адаптивная вёрстка рассчитана на 390 и 1440 px; мобильная шапка переносится, чтобы избежать наблюдавшегося в референсе обрезания ссылок.

Изучены семь локальных снимков: home, login, wall, install, home-mobile, login-mobile, wall-mobile и measurements.json. Read-only HTTP подтвердил ссылку /forgot на странице /login и содержимое /forgot. Кабинет, onboarding после регистрации, платёжные экраны и приватные состояния не изучались. Мобильный install и экран forgot не имели отдельных визуальных снимков; использована публичная структура и общая система оформления.

Локальные WOFF2 получены из публичных CSS референса для точного сравнения типографики. Бумажный фон, цвета, размеры, отступы и формы воспроизводят публичный референс; бренд заменён на Proofwall. Использование файлов шрифтов перед коммерческой публикацией должно соответствовать их лицензии.

Все отзывы синтетические и помечены demo. Реальные логотипы, персональные отзывы, реквизиты и юридические документы не перенесены. Цены и условия явно не утверждены. Формы выполняют только браузерную валидацию и показывают локальный статус; ничего не отправляется и не сохраняется. Код виджета — инертный пример. Нет авторизации, загрузок, платежей, запросов S3 или чужого JavaScript. CSP запрещает сетевые подключения и отправку форм.
