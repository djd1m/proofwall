# Авторизованный Proofo: наблюдаемая карта экранов

Дата фиксации: 11 ноября 2026. Основание — обезличенные DOM snapshots root.
Наблюдаемый аккаунт: Free, одна стена, в проекте 0 отзывов; агрегаты трафика равны 0.
Маршрут проекта в наблюдении: `/dashboard/projects-aicoding-space`; ниже его slug обозначен `:slug`.
Составитель этой карты работал только с наблюдениями координатора и самостоятельно не входил на сайт. Координатор выполнил разрешённый вход, переходы и отдельный текстовый import mode=preview; точное покрытие и границы действий — в документе08.
Значения полей и реквизиты не включены; содержимое DOM не доказывает работу серверного контракта.

- Карточка проекта ведёт в `/dashboard/:slug`, показывает адрес стены, «пока пусто», отсутствие открытий за 30 дней.
- «Ещё одна стена» заменена объяснением ограничения Free и предложением Start за 990 ₽/мес.
- Метрики за последние 30 дней: открытия стен, показы виджета, сайты с виджетом, переходы по badge; все 0.
- Empty state предупреждает: счётчик начал работать вместе со страницей; исторические значения не восстановлены.
- Не выполнено: создание стены, переход к оплате, генерация трафика и проверка обновления счётчиков.
- Reuse Proofwall: `/dashboard/page.tsx` и project/tariff lib; сейчас 1 проект вызывает redirect. Gap — общий кабинет, агрегаты периода и лимит стен.
- AC: четыре именованные метрики имеют период и нулевое состояние; Free показывает одну доступную стену и upsell.

## 2. Кабинет стены и onboarding — `/dashboard/:slug`

- Элементы: название стены, «← кабинет» → `/dashboard`, «Free · сменить» → `#tariff`.
- «Первые шаги»: 1 «Перенести отзывы» → `#import`, 2 «Проверить и одобрить» → `#reviews`, 3 «Поставить виджет на сайт» → `#show`.
- Подсказка первого шага предлагает 3–5 скриншотов; это рекомендация, отдельный лимит загрузки равен 20.
- Порядок секций: импорт → отзывы → показ людям → сбор новых отзывов → тариф → пароль.
- Открыто исходное состояние импорта со скриншотов и переключаемые текстовая и ссылочная вкладки.
- Не выполнено: прохождение onboarding до состояния с реальными отзывами или кодом виджета.
- Reuse Proofwall: server component `/dashboard/[slug]/page.tsx`; gap — новый shell, onboarding и вычисление состояния шагов.
- AC: якоря ведут к соответствующим секциям, текущий Free виден без открытия оплаты.

## 3. Импорт со скриншотов — `/dashboard/:slug#import`

- Элементы: вкладки «Со скриншотов», «Вставить текстом», «По ссылке»; input file `imp-shots`.
- Вкладка по умолчанию содержит «Выбрать скриншоты» и предложение перенести картинки в область загрузки.
- Публично заявленные ограничения: до 20 картинок, PNG или JPEG.
- Подсказка допускает скриншоты с любой площадки; распознанное можно исправить до добавления.
- В пустом состоянии «Распознать» disabled; file input доступен.
- Не выполнено: выбор файлов, OCR, предпросмотр распознанного, исправление или добавление отзывов.
- Reuse Proofwall: `platform-form.tsx` — ручной перенос через `/api/testimonials/platform`, не OCR. Gap — OCR, пакет файлов и preview/commit.
- AC: пустой пакет блокирует распознавание; UI сообщает форматы и лимит; preview/commit требуют отдельной проверки.

## 8. Форма сбора — `/f/:slug`, открыта из авторизованного кабинета

- Ссылка доступна даже при пустой стене; сама форма сообщает «Регистрироваться не нужно».
- Текстовое состояние: имя required, роль/компания optional, отзыв required, счётчик `0 / 2000`, «Отправить отзыв».
- Фото optional: JPEG, PNG или WebP, до 5 МБ; file input доступен.
- Текст согласия разрешает публикацию имени/фото владельцем; обещает неизменённый текст после проверки и возможность отзыва.
- Кабинет поясняет: внешние отзывы ждут проверки и автоматически на стену не выходят.
- Открыта видео-вкладка: «Записать с камеры», «Загрузить файл»; полей отзыва в этом состоянии snapshot нет.
- Не выполнено: отправка, загрузка фото/видео, запрос камеры, запись, модерация или финальный success screen.
- Reuse Proofwall: `submit-form.tsx`, `intake-tabs.tsx`, `video-recorder.tsx`, `/api/testimonials[/video]`; gap — сопоставить consent и UI, сохранить pending.
- AC: текст/видео переключаются; required/optional различимы; неподтверждённая отправка не считается успешной.

## 9. Free upsell — `/dashboard/:slug#tariff`

- Start: 990 ₽/мес, до 10 стен, отзывы без ограничения, снятие badge, подсветка ключевых фраз.
- Pro: 4 900 ₽/мес, стены без ограничения, всё из Start, вознаграждения и предложение дубля на Яндекс.Картах.
- Секция сбора показывает Pro gate для кампаний; награда заявлена независимо от оценки, сразу после отправки.
- UI обещает помесячную оплату и включение тарифа после подтверждения платежа; CTA Start/Pro доступны.
- Не выполнено: платёжный переход, ввод платёжных данных, смена тарифа и платные состояния кампаний.
- Reuse Proofwall: `billing-block.tsx`, `/api/checkout`, payment webhook и tariff lib; gap — Start/Pro entitlements, кабинеты кампаний и новый pricing UI.
- AC: Free не показывает активную подписку; цены и возможности отражают наблюдённый текст; checkout не имитируется.

## 10. Пароль — `/dashboard/:slug`, раскрытие секции

- Закрытый вид: «Сменить пароль» и предупреждение о завершении входов на прочих устройствах, кроме текущего.
- Открытый вид: три required password-поля — текущий, новый от 8 символов, повтор; submit и «Отмена».
- Snapshot раскрытия сохраняет выбранную вкладку импорта; смена пароля не является отдельным маршрутом.
- Открыто и отменено: после «Отмена» все три password-поля исчезли, осталась кнопка раскрытия; мутация не выполнялась.
- Reuse Proofwall: `change-password.tsx` и `/api/auth/password`; не проверены серверные ошибки и обещанный отзыв прочих сессий.
- AC: открыть форму, отменить и вернуться к закрытому виду без мутации; submit требует отдельной авторизованной проверки.

## Источники и границы точности

Snapshots: `dashboard-main`, `import-text`, `import-link`, `password-expanded`, `password-cancelled`, `branding`, `dashboard-list`, `collection-text`, `collection-video`, `empty-wall`.
Mobile: `dashboard-mobile`, `dashboard-list-mobile`, `branding-mobile`, `collection-mobile`, `collection-video-mobile`, `password-mobile`.
У пяти пар desktop/mobile совпали route, headings, текст, кнопки и поля; это подтверждает состав UI, но не геометрию и адаптивность.
Reuse уточнён по `02_reuse_inventory.md`; исходники повторно не читались, runtime API не вызывались. Gap означает отсутствие соответствия, а не доказанный отказ API.

Root дополнительно обнаружил в статическом JS Proofo `/api/import`, `/api/import/link`, `/api/import/screenshot`, `/api/import/avatars`, `/api/checkout`, `/api/campaigns`, `/api/auth/password`.
За исключением текстового предпросмотра из документа 08, эти клиентские вызовы не исполнялись. Статические фрагменты показывают отдельные поля payload, но полного серверного контракта не подтверждают; совпадение пути с Proofwall не доказывает совместимость.
