# Макет исследованного кабинета

Изолированный статический модуль для обсуждения владельцем. Основание — `07_authenticated_screen_map.md` и `08_authenticated_interaction_coverage.md`; геометрия сверена с обезличенными приватными снимками. Используется навык `.agents/skills/frontend-design/SKILL.md` в границах воспроизведения существующего визуального языка. Исходные снимки, аккаунт и реквизиты в публичные файлы не переносятся.

Подключение: `cabinet.css` после `style.css`, `cabinet.js` перед `preview.js`. API `window.CabinetPreview`:

- `hasScreen(screen)` — поддерживается ли экран.
- `render(screen, {link, brand, footer})` — возвращает HTML; `link(screen, anchor='')` передаётся существующим mockup-навигатором, `brand()` и `footer()` — общие render-функции. Все переходы между экранами используют helper; якоря остаются локальными.
- `mount(root)` — подключает обработчики после вставки HTML в `root`. Внешний глобальный form submit-handler не должен вмешиваться в формы `data-cabinet`; обработчик модуля останавливает всплытие.

Готовы экраны: `dashboard`, `project`, `branding`, `collect`, `collect-video`, `empty-wall`. Навигация — относительные `?screen=…`; адрес самого preview задаёт host. Маркер «Макет кабинета · данные вымышлены · без записи» остаётся видимым при `clean=1`.

В проекте доступны три режима переноса, локальный предпросмотр одной текстовой строки «Имя; текст», empty reviews/show gate, переходы в оформление и сбор, тарифный якорь, раскрытие и отмена трёх полей пароля. Кнопка добавления даёт только пояснение; число отзывов и пустое состояние не меняются. Скриншоты не читаются, OCR disabled. Ссылка не запрашивается. Сохранение оформления, отправка форм, оплата и пароль дают демонстрационный статус без записи. Пароль очищается при отправке и отмене, не сериализуется и не выводится. Перед полями пароля и формой сбора показано предупреждение о демоданных.

Оформление содержит две темы, три порядка, метки источников, цвет, URL логотипа и заголовок формы. Тема/порядок не применяются к не наблюдённой заполненной стене. URL логотипа не используется как src. Видеовкладка содержит выбор метода, локальную форму файла, пояснение об отключённой камере без запроса разрешения. Файлы существуют только в нативном input; модуль не читает содержимое.

Не реализованы и не изображены как подтверждённые: populated review-cards, результат commit/OCR/link-import, рабочий embed, активные платные тарифы, кампании и запись камеры. Визуальная структура адаптирована для 1440/390; host выполняет браузерный QA. Авторская локальная проверка ограничена синтаксисом JS и статическим просмотром; это не независимое ревью или приёмка приложения.
