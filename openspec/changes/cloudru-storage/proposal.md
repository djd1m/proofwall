## Why
Владелец выбрал существующий частный Cloud.ru bucket `proofwall` для запуска Proofwall на VPS 78.17.53.233 с HTTPS sslip.io. Локальные клиенты пока жёстко используют MinIO path-style.

## What Changes
- Параметры региона/адресации и совместимые checksum-настройки двух существующих клиентов.
- Один private bucket для фото/видео; MinIO становится опциональным.
- Документация ключей владельца, локальные проверки и отдельная runtime-приёмка после ключей.

## Impact
Без изменений БД, object keys, TTL, UI, транскрипции и оплат. Реализация и runtime-приёмка ещё не выполнены. План и ADR: `features/cloudru-storage/`.
