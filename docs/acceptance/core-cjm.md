# Базовая приёмка Proofwall

Начальный список для нового окружения, 11.11.2026. Основан на собственных требованиях
N1, а не на сценариях Clipmkr. Сейчас эти сценарии на данном VPS не проверены.
Точные FR и критерии — `../Specification.md`; новые изменения задаются OpenSpec-дельтами.

1. Владелец регистрируется/входит, создаёт проект и получает ссылки на сбор/стену/виджет.
2. Посетитель оставляет текстовый отзыв; владелец модерирует его, публикация видна на стене.
3. Виджет работает на внешнем домене; экранирование и изоляция арендаторов проверены.
4. Badge зависит от серверного тарифа; установка учитывается на пару project/domain.
5. Оплата в явно выбранном TEST-окружении: идемпотентный webhook, срок тарифа,
   отсутствие доступа к чужому проекту и корректное состояние после отказа/повтора.
6. Для включаемых в задачу видео, импорта, партнёрки и агентных платежей — отдельные
   применимые критерии соответствующих FR, без выдачи выключенной функции за проверенную.

Проверять desktop/mobile, ошибки и повторные действия. Выдать владельцу ссылку,
инструкцию и ограничения для ручной приёмки. Наличие этого файла не означает,
что новый стенд, цены, домен или production-публикация согласованы.
