# Независимое ревью Proofwall

Адаптация процесса Clipmkr, 11.11.2026. Для новых продуктовых изменений применяется
cross-model: автор и проверяющий — разные модели; новая сессия без истории кодирования.
Матрица — `model-matrix.md`. Разный reasoning effort одной модели не создаёт cross-model.

Проверяющему передать согласованные требования/OpenSpec, ADR, архитектуру, план и SHA
артефакта. Он самостоятельно изучает код и тесты. Прежние авторские выводы и ревью
не являются исходными доказательствами. Для агентного запуска использовать
`fork_turns=none`; фиксировать фактические model ID, сессию и входы.

Отчёт: severity, файл/строка, сценарий, конкретная находка и ограничения. Исправления
существенных находок возвращаются на независимую проверку. Недоступная модель/CLI
означает невыполненное ревью, а не разрешение заменить его авторской самопроверкой.
Текущий перенос репозитория проверен автором; cross-model/QE приложения не проводились.
